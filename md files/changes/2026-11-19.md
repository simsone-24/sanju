# Changes — 2026-11-19

## Quotations — line-item layout is available again, alongside section-wise

A new quotation can be entered either **section-wise** (items grouped under sections, one amount per section) or as **line items** (the original table: item, quantity, unit price, subtotal). The choice is a "Quotation layout" switch above the lines; both drafts are kept, so switching back and forth never loses what was typed. A saved quotation keeps the layout it was saved in.

**Files created**
- `client/src/pages/quotations/QuotationLayoutToggle.tsx` — the Section-wise / Line items switch.

**Files modified**
- `client/src/pages/quotations/QuotationFormPage.tsx`, `client/src/pages/enquiries/EnquiryQuotationDialog.tsx`, `client/src/pages/enquiries/EnquiryFormPage.tsx` (the quotation drafted together with a new enquiry) — layout switch on new quotations; totals, preview and save follow the chosen layout.

**Database / API changes**
None — the API already accepted either `items` or `sections`.

**Follow-up notes**
- The switch is shown when creating; editing a saved quotation does not offer it (converting would lose quantities / rates, or the section grouping).

## Quotations — section-wise and line items in the same quotation

A quotation can now carry **both**: section-priced groups (one amount per section) and individually priced line items (item, quantity, unit price, subtotal). The "Quotation layout" switch has a third choice, **Both**; with it the sections and the line-item table are shown together under one set of tax / advance / total fields, and either part may be left empty as long as the quotation has at least one line. The subtotal is the sections' amounts plus the line items' subtotals.

**Files modified (client)**
- `pages/quotations/QuotationLayoutToggle.tsx` — third option (Both); a saved quotation is offered only layouts that cannot drop what it holds (it can gain the other kind of line, never lose one).
- `pages/quotations/QuotationFormPage.tsx`, `pages/enquiries/EnquiryQuotationDialog.tsx`, `pages/enquiries/EnquiryFormPage.tsx` — Both layout, combined totals, combined save.
- `pages/quotations/QuotationSectionsEditor.tsx`, `QuotationItemsEditor.tsx` — `showTotals` option so the totals are shown once.
- `pages/quotations/quotationDraft.ts` — `quotationMixedTotals`, `flatItemAsSection`, optional-empty parsing.
- `pages/quotations/QuotationPreview.tsx`, `QuotationDetailPage.tsx` — a mixed quotation shows as one section table with its line items after the sections as groups of one (Size/Qty column reads "quantity × rate").
- `pages/enquiries/EnquiryQuotationActions.tsx` — Duplicate copies both kinds of line.

**Files modified (server)**
- `modules/quotations/validation.ts`, `types.ts` — update accepts `items` and `sections` together (create already did).
- `modules/quotations/service.ts` — the PDF prints a mixed quotation as one section table (line items follow the sections as one-item groups, Size/Qty "qty x rate").

**Database changes**
None.

**API changes**
`PUT /api/quotations/:id` no longer rejects a body with both `items` and `sections`; sending either or both replaces every line of the quotation.

**Follow-up notes**
- An invoice already listed both kinds (one line per section, then the priced items).
- Verified against the database (create and update with both, then with sections only), rolled back. Not yet exercised in the browser.

## Quotation preview / PDF — blank instead of 0 or a dash; item dropdown in sections

**Files modified**
- `client/src/pages/quotations/QuotationPreview.tsx`, `server/src/modules/quotations/pdf.ts` — in the line-item table the Quantity, Unit Price and Subtotal cells are left blank rather than showing "—" or 0: a quantity of 1 (the form's default) or 0 is not shown, and a zero price / subtotal is not shown. A quantity typed as 2 or more still prints.
- `client/src/pages/quotations/quotationDraft.ts`, `server/src/modules/quotations/service.ts` — a priced line item shown inside the section table (mixed quotations) gets a blank Size/Qty when its quantity is 1 or 0, instead of "1 × price".
- `client/src/pages/quotations/QuotationSectionsEditor.tsx` — each item row in a section is now a dropdown of item **names** from the Stock Items master (no quantity, stock or price shown); free text still works.

**Database / API changes**
None.

**Follow-up notes**
- The form still defaults Quantity to 1 (as chosen); only the document hides it. The quotation view page's own item table is unchanged.
