## Quotation PDFs re-render after Company Settings change

- **Files modified:** `server/src/modules/quotations/service.ts`
- **What/why:**
  - `getPdfForDownload` now re-renders a cached quotation PDF when the company's `updated_at` is newer than the file.
  - Without this, a new logo, bank details or terms never reached quotations that were already saved: they were only re-rendered when the quotation itself changed.
  - A company "letterhead" feature was built earlier the same day and removed at the user's request before commit. No letterhead code, column, SQL file or migration remains; the local `companies.letterhead` column was dropped.
- **Database changes:** None
- **API changes:** None
- **Notes:**
  - The WhatsApp first-page preview is generated by WhatsApp on the sending device, not stored in the PDF.
  - The invoice that lacked a preview was sent from WhatsApp on a computer.

## Reports → Orders tab: order values hidden

- **Files modified:** `client/src/pages/reports/tabs/OrderReportTab.tsx`
- **What/why:**
  - The Orders tab on the Reports page now shows counts only, as the Dashboard's Reports tab already did.
  - Removed: the "Value" total, the "Order Value by Day/Week/Month" chart, and ₹ amounts in the trend tooltips and the Orders by Event Type list.
- **Database / API changes:** None. `/reports/orders` still returns the amounts, so this only hides them in the browser.
