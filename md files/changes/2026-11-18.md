# Changes — 2026-11-18

## Soft delete for quotations

A quotation can now be deleted. It is a soft delete: the row stays with `deleted_at` set and drops out of every list, view and total (all quotation queries already filtered on `deleted_at`).

**Files modified (server)**
- `modules/quotations/` (`routes.ts`, `controller.ts`, `service.ts`, `repository.ts`) — `DELETE /api/quotations/:id` (`QUOTATIONS → canDelete`). Refused when an order was raised from the quotation, or while the quotation is confirmed (Approved) — a confirmed quotation feeds the enquiry's final budget and the order, so it must be un-confirmed first. For an enquiry-sourced quotation the enquiry's quotation amount / version are re-pointed at the newest remaining quotation (cleared when none is left). The delete is logged (`DELETE`).
- Revision numbering now counts deleted revisions (`findLatestQuotationForEnquiry(..., includeDeleted)`), because a deleted revision still holds its (enquiry, version) pair under the unique index; a new revision continues the version count instead of colliding.
- `modules/permissions/catalog.ts` — **Delete** added to the Quotations permissions.

**Files modified (client)**
- `services/quotationService.ts` (`remove`); `pages/quotations/QuotationListPage.tsx` (row menu → Delete), `pages/quotations/QuotationDetailPage.tsx` (⋮ menu → Delete Quotation, then back to the list), `pages/enquiries/EnquiryQuotationActions.tsx` (delete icon in an enquiry's quotation table). Each asks for confirmation and only shows with the Delete permission.

**Database changes**
None (`quotations.deleted_at` already exists).

**API changes**
`DELETE /api/quotations/:id` → `{ success, message: "Quotation deleted successfully.", data: null }`; 404 if not found; 400 if an order was raised from it or it is confirmed.

**Follow-up notes**
- Nobody has the new Delete permission until it is granted (Settings → user group permissions); a Super Admin has it already if the role bypasses checks.
- If the deleted revision was the newest, the previous one stays marked "Revised" (no automatic restore of its old status).
- There is no screen to view or restore deleted quotations; they can only be restored in the database.
