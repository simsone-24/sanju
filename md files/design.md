# Layout Structure

Use a clean application layout without a top header.

```
+----------------------+--------------------------------------+
|                      |                                      |
|                      |                                      |
|      Sidebar         |          Main Content                |
|                      |                                      |
|                      |                                      |
|                      |                                      |
+----------------------+--------------------------------------+
```

The sidebar should remain fixed on the left and contain all primary navigation.

The main content area should include:

- Breadcrumb navigation
- Page title
- Page description
- Primary action button (e.g., **+ New Booking**)
- Search and filters for the current module
- Module content (cards, tables, forms, charts, etc.)

---

# Sidebar

The sidebar should provide all navigation and quick access features.

Include:

- Company Logo
- Collapse/Expand button
- Dashboard

### Operations
- Enquiries
- Quotations
- Bookings
- Calendar

### Management
- Customers
- Payments
- Tasks
- Vehicles
- Inventory

### Administration
- Reports
- Masters
- Users
- Roles
- Settings

The sidebar should remain fixed while the content area scrolls independently.

---

# Page Header (Inside Content)

Each page should begin with a simple page header instead of a global top navigation.

Example:

Bookings

Manage all customer bookings and event details.

                                [+ New Booking]

Below the page header, display:

- Search
- Filters
- Export
- Refresh
- View Options

Then display the page content.
